Research Context

Input

Five-minute wearable PPG windows and engineered physiological signal features.

Architecture

CatBoost gradient-boosted trees combined with a Temporal Convolutional Network through validation-selected probability fusion.

Validation

Dexcom CGM acts as retrospective ground truth and is not supplied as an input to the prediction model.

GlycemicPlus is an experimental research prototype. Current performance is not sufficient for clinical use. It should not be used for diagnosis, insulin dosing, or treatment decisions.
